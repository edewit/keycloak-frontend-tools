Why these projects exist

Frontend developers want to build features — not fight clunky Freemarker templates, disconnected redirect pages, or a backend security black box they try to avoid.

Modern auth libraries won hearts with magic type inference, native UI control, and zero redirects. But they sacrifice multi-realm isolation, OIDC compliance, and enterprise-grade architecture.

These projects bring that DX to Keycloak — without the trade-offs.

The old enterprise way

  • Fighting Freemarker just to change a CSS style
  • Hard to integrate into your application
  • Default themes that feel like 2005

What developers want

  • Typed roles and permissions in the IDE
  • Login forms as standard app components
  • Frameworks they already know — React, Vue, Svelte
